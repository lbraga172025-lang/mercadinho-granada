# Mercadinho Granada - Dicionário de Dados

Sistema de Gestão Operacional e Vendas - Mercadinho Granada

Site com o Dicionário de Dados completo do banco de dados do projeto.

## 🔗 Site no ar

https://lbraga172025-lang.github.io/mercadinho-granada/

## 📁 O que tem aqui

- `index.html` - Página principal do Dicionário de Dados
- `style.css` - Estilo do site
- `script.js` - Busca e filtros das tabelas
- `docs/` - Documentação do projeto

## 🗄️ Tabelas do banco

Cliente, Pedido, Produto, Estoque, Fornecedor, Entrega, Pagamento e outras tabelas do sistema de vendas, delivery e controle de estoque.

## 🚀 Como usar

É só abrir o link do site e pesquisar pela tabela que você quer ver.
